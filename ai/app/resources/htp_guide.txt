# 🧠 HTP 투사검사 통합 정밀 분석 가이드

### *(YOLO 객체 탐지 기반 · 자아와 환경의 역동적 표상 분석)*

---

## 0️⃣ 해석의 목적과 원칙

이 가이드는 집·나무·사람 그림과
YOLO 객체 탐지 결과를 결합하여 사용자의 내면 상태를 **입체적으로 이해하기 위한 분석 기준**입니다.

### 핵심 원칙

* 단순 묘사가 아니라 **심리적 의미로 번역**합니다.
* 모든 해석은 **가능성**의 언어로 표현합니다.
* 진단이 아니라 **자기이해를 돕는 심리적 가설**입니다.

❌ “우울하다”
✅ “최근 정서적 에너지가 많이 소진되었을 가능성이 있습니다”

# 1️⃣ 조형적 요소의 공통 해석

### *(Gestalt & Psychological Energy)*

그림의 전체 인상은 자아 강도와 정서적 에너지 수준을 보여주는 기초 지표입니다.

| 분석 요소     | 긍정적 의미 (강점/회복력)          | 어려움 신호 (취약성/방어)                                  |
| --------- | ------------------------ | ------------------------------------------------ |
| **전체 크기** | 적절한 크기 → 안정된 자존감, 환경 적응력 | 매우 작음 → 위축·자신감 저하 가능성<br>매우 큼 → 과시적 표현·통제 욕구 가능성 |
| **필압·선**  | 강하고 안정된 선 → 의지·결단력       | 흐릿한 선 → 에너지 저하·불안 가능성<br>잦은 덧칠 → 완벽주의적 긴장        |
| **지면선**   | 지면 존재 → 현실 기반 안정감        | 지면 부재 → 기반 불안정·소속감 고민 가능성                        |
| **위치**    | 중앙 배치 → 심리적 균형감          | 하단 밀착 → 무기력·위축 가능성<br>상단 밀착 → 공상 몰입 경향           |

# 2️⃣ 🏠 House — 가정생활 및 관계 안정성

**YOLO 탐지 클래스**
집전체, 지붕, 문, 창문, 굴뚝, 연기, 길, 울타리, 잔디, 꽃, 태양, 산, 연못

| 탐지 객체     | 긍정적 해석                 | 어려움 신호                                          |
| --------- | ---------------------- | ----------------------------------------------- |
| **지붕**    | 건강한 상상력, 사고 활동         | 지나치게 큼 → 현실 부담 회피 가능성<br>빈약/생략 → 정서적 여유 부족 가능성  |
| **문·창문**  | 적절한 개수·크기 → 원활한 소통 의지  | 부재/닫힘 → 관계 거리두기 경향<br>과도하게 많음 → 외부 인정 욕구 증가 가능성 |
| **굴뚝·연기** | 은은한 연기 → 정서적 온기, 감정 교류 | 짙은 연기 → 긴장·감정 억압 가능성                            |
| **길**     | 넓은 길 → 관계 접근성·개방성      | 좁고 긴 길 → 관계 맺기 망설임                              |
| **울타리**   | 적절한 경계 설정              | 강한 방어·타인 경계 가능성                                 |
| **잔디·꽃**  | 정서적 안정·조화 추구           | 과도한 장식 → 불안 보상 가능성                              |
| **태양**    | 낙관성·활력·권위와의 긍정적 관계     | 과도한 강조 → 평가 압박 민감성                              |
| **산**     | 심리적 지지 기반              | —                                               |
| **연못**    | 정서적 성찰                 | 정서 침체·내면 고립 가능성                                 |

# 5️⃣ 심리적 경고 신호 (주의 깊은 해석 필요)

아래 요소는 **진단 지표가 아닌**,
정서적 어려움 가능성을 시사하는 *관찰 신호*입니다.

| 영역     | 관찰 신호          | 가능 해석            |
| ------ | -------------- | ---------------- |
| 정서 위축  | 매우 작은 그림, 흐린 선 | 활력 저하·자신감 감소 가능성 |
| 정서 긴장  | 짙은 연기, 강한 필압   | 감정 압박·스트레스 가능성   |
| 고립 경향  | 문·창문 부재, 눈 생략  | 관계 거리두기 가능성      |
| 에너지 소진 | 처진 가지, 잎 없음    | 휴식 필요 신호         |
| 억눌린 긴장 | 주먹 쥔 손         | 감정 표현 억제 가능성     |

# 6️⃣ 통합 해석 원리

### ① 강점 우선 원칙

부정적 신호가 있어도
꽃, 태양, 위로 뻗은 가지 등 긍정 요소가 함께 있다면
이는 회복 자원과 적응 가능성을 의미합니다.

### ② 결핍의 의미

필수 요소 부재는 단순 누락이 아니라
해당 영역에 대한 심리적 회피 가능성을 시사합니다.

* 문 없음 → 관계 접근 부담
* 눈 없음 → 외부 인식 회피
* 뿌리 없음 → 기반 불안정 고민
